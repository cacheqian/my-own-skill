# 视觉规范与样本观察

用于制作画板、排版富文档，或需要追溯本 Skill 的风格依据时阅读。基础改写无需重新访问样本文档。

## 学习来源与边界

- 样本：[投放 Agent One-page](https://bytedance.larkoffice.com/docx/Ncf4dhiVHoI4TGxDusKci9UBnLg)。
- 只读学习日期：2026-10-09；读取版本：revision 880。
- 已读取全文及格式元数据，查看 3 张画板、其原始节点与 7 张界面配图。正文共 6 张原生表格；没有独立的趋势或分布类数据图表。
- 样本业务主线为产品概览、功能与技术框架、业务及能力模块建设进展、Q4 规划，末尾提供参考链接。
- 以下观察仅说明该版本的表达方式，不确认其中的业务主张或当前进展。用户本次明确的“关键画板优先 1～2 张”高于样本实际的 3 张。

## 文字与页面格式：观察到的做法

| 位置 | 样本做法 | 可复用的规则 |
|---|---|---|
| 核心定义 | 浅蓝提示块内放一句加粗定义 | 让读者先知道对象与用途 |
| 术语 | Loop、Skill、HITL 首次出现时紧跟中文解释 | 解释一次，避免读者反复查词 |
| 核心价值 | 三项短列表，以加粗价值标签开头 | 用收益引领说明，避免堆功能名 |
| 章节 | 一级中文编号、二级小数编号；技术节局部使用三级标题 | 用稳定层级导航，第三层按需 |
| 重点 | 结论和关键数字加粗，少量技术判断加下划线 | 强调应克制；默认用加粗即可，不机械复制下划线 |
| 表格 | 多为 2～3 列，窄标签列、宽说明列，部分表头浅灰，内容顶端对齐 | 结构承担信息密度，保留足够列宽 |
| 界面说明 | “功能／能力说明／交互示例”三列表；关联截图在同一格并排 | 让能力说明与实际交互对应 |
| 参考资料 | 末尾按用途列链接 | 深层背景移至引用，关键证据仍贴近结论 |

One-page 指快速建立整体认知，不等于把整篇报告压成一张小字图片或严格一页纸。

## 三张画板各自承担什么

| 画板 | 观察到的构图 | 迁移用法 |
|---|---|---|
| 统一能力架构 | 左侧三层横向分区，右侧反馈回路，底部简短闭环与规划说明；蓝色当前模块、橙色规划模块 | 系统有明确分层与反馈时，用一张总览图说明全局 |
| 创建与调控运行机制 | 左侧运行框架、中间对话过程、右侧执行分支；底部独立巡检，连接线标明交互 | 复杂机制可用泳道；管理汇报应收敛细节，避免原样复刻密集工程图 |
| 关键运行保障 | 上方横向五步主链路，下方三个保障模块，底部橙色后续建设提示 | 解释“一条主流程＋贯穿能力＋后续缺口”时可采用 |

选图时先检查解释是否重叠。例如总览图已说明分层与闭环，第二张只保留真正需要展开的运行机制；保障能力可以移为表格，不必另占一张画板。

## 可复用的样式值

以下颜色从画板原始节点读取；作为默认值，不覆盖用户的品牌或团队规范。

| 用途 | 样本色值 | 使用方式 |
|---|---|---|
| 主文字 | `#1F2329` | 标题、模块名、核心内容 |
| 辅助文字 | `#646A73` | 短说明与次级标签；关键条件不要灰到难读 |
| 当前链路／主强调 | `#3370FF` | 关键描边、流程编号与主线 |
| 浅蓝区域 | `#F0F5FF` | 同类模块或保障能力的分组背景 |
| 浅灰分区 | `#F5F6F8` | 大层级容器，保持白色卡片可辨 |
| 边框与分隔 | `#DEE0E3` | 细边框、分隔线 |
| 规划强调 | `#D48806` | 搭配“规划／后续建设”文字 |
| 规划底色 | `#FFF7E6` | 小面积标出未来能力 |

正文提示块在样本中使用 `#F0F4FF` 背景、`#82A7FC` 边框。无需为还原色值改变平台默认字号或影响可读性。

## 制图与配图建议

以下是为复用而提出的建议，不是样本像素级规格：

- 同篇画板统一标题层级、圆角、线宽、箭头、字体和卡片内边距。图标只在帮助识别模块时使用，采用同一套简单线性图标。
- 总览优先横向或紧凑分层布局；画布应贴合有效内容。样本部分导出预览下方留白很大，这不是需要继承的风格。
- 每个节点优先短标题加一两行说明；超量信息移入正文或表格。先确定关系，再排列卡片，避免交叉连线。
- 流程、反馈和独立执行分别明确标注。实线、虚线一旦具有特定含义，全文保持一致；不要靠颜色单独区分状态。
- 截图仅保留理解入口、操作或结果所需的区域；统一展示宽度与短标题，保留必要状态和上下文。两张并排后若文字无法辨认，改为纵排或保留一张关键图。
- 数据图表是本 Skill 的扩展建议，样本中没有可照搬的数据图风格。趋势用折线、类别数量比较用条形；统一统计期、轴、单位与图例，有目标线时注明目标口径。少量精确数字仍用表格。
- 预览时检查：正常文档宽度下文字可读、无重叠裁切、分组边界清楚、连线能追踪、规划标记明确。图表需要用户放大很多倍才能理解时，应继续简化。
