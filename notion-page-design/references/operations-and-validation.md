# 操作选择与验证

## 按实际连接器执行

优先已可用的 Notion 能力。增强 Markdown、原生 block API、浏览器编辑有不同格式和可写范围；先发现工具与参数，不根据别的平台命令拼接名字。官方文档与当前 schema 用于解决真实缺口，不为简单编辑扫描无关资源。

增强 Markdown 示例见 [native-blocks.md](native-blocks.md)。若当前连接器没有这种格式，使用它支持的原生块结构，不把自定义标签直接塞进普通段落。读过且仍有效的文档可复用；新参数、未知类型或版本变化再查具体规范。

## 精确修改

| 变更 | 实施方式 |
|---|---|
| 小段文字、数值、名称 | 按 block ID／唯一文本锚点局部修改，只提交所需字段 |
| 增补章节或图 | 在实际目标块前／后插入，保留相邻内容 |
| 修改既有图或附件说明 | 使用既有块及引用，不创建第二张页或新对象替代 |
| 重写一节 | 回读完整章节与其子块，再替换该范围 |
| 全面重写 | 保留资源和子页面映射，确认读取完整，按支持的机制回写 |
| 页面结构调整 | 区分链接、移动块和重新挂接页面；检查实际结构结果 |

从当前返回值取得 ID、引用和版本，不手写猜测。精确锚点出现多次时加入足够上下文；不要用模糊词或宽泛正则替换。支持版本／hash 防护时携带实际值，发生并发变化后重读受影响部分并重建剩余修改。

完整替换与局部 patch 不同，数组字段是否全量覆盖以 schema 为准。仅修改标题时不附带正文、附件或未改变的属性。保留同步块、数据库、子页、原生提及、图片及未知对象；模型看到的文本投影不等于完整对象结构。

原生页面 mention 与创建／移动子页的标签可能有不同语义，使用实际规范。表格单元格、分栏和折叠有各自嵌套限制，跨容器范围不默认有效。当前未知块无法完整回写时，缩小修改范围，保留原对象。

## 批量、异步与失败

独立读取可批量并行；同一页面的依赖写入按顺序完成，避免锚点或版本互相失效。分页遵循真实 `has_more`／cursor 语义，完整读取与有界抽样明确区分。

检查顶层状态、业务结果、warning、忽略原因和每项 receipt。异步 accepted 只是已接受，等待工具定义的终态；上传成功还需绑定正确对象。保存、渲染、分享、发布和定时运行各自确认，不能互相证明。

| 故障 | 下一步 |
|---|---|
| 参数／schema 错误 | 查实际规范，修正错误参数后重试一次 |
| 版本过期／并发冲突 | 读取受影响部分，保留新的人工编辑，再生成剩余改动 |
| 超时／未知是否成功 | 先查任务或回读现状，再决定重试，避免重复插入 |
| 批量部分成功 | 留住成功项，仅修复未成功项 |
| 已知不支持／无权限／硬限制 | 停止猜测接口或重复同一路径；保留已完成结果并说明缺口 |
| 限流／可恢复临时失败 | 按工具建议退避，有界重试；不无限轮询 |

工具返回有下一步恢复方式时优先采用。已删对象不自动重建，失败不通过复制整页、清空正文或换目标绕过。

## 四层核验

1. **内容**：请求全部落实，事实、数字、引用归属、版本、术语和状态正确；无临时草稿、误导性示例或占位。
2. **结构**：新内容的位置、标题与嵌套、表格记录数、分栏顺序和页面关系符合预期；原有对象仍在。
3. **资源与代码**：附件数与引用完整；Mermaid 是 `mermaid` 语言的代码块，源码未经意外转义；未知块与必要元数据保留。
4. **视觉**：有真实预览时检查文字、布局、裁切、图像加载、解析、连线、对比度与窄屏阅读。回读不能替代渲染检查。

新页、大改、布局变动或资源保留敏感的编辑需要回读。小改已有完整确认时避免反复读整页。发现具体问题后只修对应范围，再核验变化部分；没有新问题不重复扩大检查。

交付返回真实页面链接，说明关键变化和实际未验证／未完成的部分。部分成功不称全部完成；没有写入能力时交付草稿并写清状态。
