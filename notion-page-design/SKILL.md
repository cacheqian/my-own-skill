# Notion 页面设计

把内容组织成能独立阅读、方便扫读和继续编辑的页面。先确定读者需要理解、决定或执行什么，再选择原生块与视觉形式；版式不能改变事实或制造结论。

## 先判断编辑模式

| 用户意图 | 做法 |
|---|---|
| 新建页面／导入资料 | 提炼读者任务与主线，组织为原生页面，保留来源与必要素材 |
| 重写介绍／重新组织 | 改写结构与表达，保留事实、证据强度和指定内容 |
| 仅排版／美化 | 保留措辞、数据、公式、链接、语气和完成状态；调整层级与展示 |
| 补一张图／添加 Mermaid | 只改指定图及相邻说明；要求保留原图时并存 |
| 更新事实／维护页面 | 把新证据合入对应位置，合并重复项，保留人工修改和历史记录 |

读现有页面、目标附近内容及实际资料。参考页面和模板先读后用；识别截断、未展开的子块和无法识别的资源。信息足够时直接执行，只有会实质改变结果的缺失信息才澄清。

## 用内容决定版式

新建或大幅重写时，先用简短设计说明确定：读者与阅读任务、核心结论、章节顺序、每节要回答的问题、密度、视觉焦点，以及需保留的素材。小改无需完整规划文件。

- **开头**：给具体结论和必要背景；工作型页面先展示状态、决定或待办。使用原生页面标题，正文不重复标题。
- **正文**：按问题与逻辑递进；一节承担一个主要任务。用连贯段落说明关系，步骤用编号，并列项用列表。
- **分栏**：两到三组简短且等权的信息。长段落、顺序流程和宽表留在主栏；手机端堆叠后仍须读得通。
- **表格**：精确比较、字段映射、重复记录。表头写清单位与口径，长解释移到表外。
- **Callout**：核心结论、重要限制或行动提示。普通段落不全装进卡片；强调保持稀少。
- **折叠与导航**：收纳源码、参数、详细依据和附录。核心结论、决定所需证据及关键限制保持可见；长页按需加目录。

沿用已有模板或参考中有效的视觉语言。新设计分别选择信息结构、密度和配色，避免只换颜色或全篇机械复用同一种布局。颜色承担稳定语义，图标与编号承担导航；用文字同时表达状态，不仅靠颜色。Notion 原生色板与可用布局决定最终样式，不承诺任意字体、CSS 或像素坐标。

需要选体裁、密度或章节布局时读 [页面模式](references/page-patterns.md)。

## 让正文、来源与图互相支撑

事实、源码观察、计算、假设与判断用恰当措辞区分。日期、单位、版本、引用归属和证据强度保持准确；数据缺失不能写成零。图旁给一句读图结论及必要范围，图中每条业务连线都有实际含义。

按阅读任务选择形式：

| 需要表达什么 | 优先形式 |
|---|---|
| 精确值、字段、方案差异 | 原生表格；持续跟踪时再选数据库 |
| 流程、依赖、时序、层级、状态 | 原生 `mermaid` 代码块 |
| 可直接编辑的并列文字卡片 | 分栏与 Callout |
| 外观、实物、截图、原始证据或插画 | 图片，配说明与来源 |
| 趋势、占比、数据探索 | 当前工具实际支持的原生图表或数据库视图 |

用户指定保留图片时，保留原图及其说明，再添加 Mermaid。Mermaid 编辑源码并自动布局；分栏卡片可直接编辑文字，但没有绑定连线。按需使用图片，不为美化任务默认生图、安装工具或引入外部画板。

- 论文、源码、网页、视频、会议或多语言资料：读 [内容与来源](references/content-and-sources.md)。
- 图型选择、Mermaid、封面与图片处理：读 [图与媒体](references/diagrams-and-media.md)。
- 指标、数据库、视图或数据图表：读 [数据展示](references/data-and-views.md)。

## 写入与核验

发现当前可用的 Notion 工具并读取实际参数与格式规范。支持增强 Markdown 的连接器可读取其 `notion://docs/enhanced-markdown-spec`；使用原生 API 时以当前 API 版本和块结构为准。示例不是所有连接器都支持的通用语法。

局部修改优先用已读取的 block ID 或唯一的精确文本锚点；仅提交需要改变的字段。已有页面和图原地更新，不通过新建副本实现修改。全面重写前保留子页面、数据库、同步块、提及、评论相关对象和其他指定内容；无法完整读取或回写的资源不经文本投影重建。

复杂布局、批量操作或连接器异常时读 [操作与验证](references/operations-and-validation.md)。需要原生块写法或三组架构示例时读 [原生块示例](references/native-blocks.md)。

写后核对实际内容、位置、关键事实、资源完整性及每项操作结果。保存成功、异步任务完成、图像上传完成和客户端渲染是不同状态；未知结果先回读再重试，仅修复失败部分。结构变化与保留敏感的修改要回读；小改有明确服务端确认时避免重复读取整页。

有页面预览时检查层级、分栏顺序、表格可读性、图片加载、Mermaid 解析和浅深主题下的对比度。没有预览时说明已验证保存内容，不声称验证过视觉效果。交付页面链接、实质变化及尚未解决的缺口；编辑提示只放帮助读者继续操作的必要一句，写作过程和工具日志不进入正文。
